- [x] Confirmar os nomes e o escopo das variáveis exigidas pela integração existente.
- [x] Habilitar a configuração segura de variáveis no projeto.
- [x] Inserir a URL e a chave publicável do Supabase fornecidas pelo usuário.
- [x] Validar autenticação, sessão e acesso ao gerenciamento de pacientes.
- [x] Diagnosticar e corrigir a autenticação com Google — escopo substituído pela remoção temporária do provedor.
- [x] Diagnosticar e corrigir a criação de conta por e-mail e senha.
- [x] Habilitar o provedor Google e cadastrar o redirecionamento do preview nas configurações do Supabase — adiado por decisão do usuário.
- [x] Remover temporariamente o botão e o fluxo de autenticação com Google.
- [x] Validar a interface de acesso somente por e-mail e senha.
- [x] Remover da interface a mensagem e a etapa de confirmação por e-mail após o cadastro.
- [x] Designar adminportage@gmail.com como administrador principal com acesso imediato.
- [x] Aplicar aprovação obrigatória para novos usuários não administradores.
- [x] Validar que somente administradores podem liberar o acesso de novos usuários.
- [x] Verificar no banco que um usuário profissional não consegue atualizar aprovações.
- [x] Verificar no banco que o administrador principal consegue aprovar um usuário pendente.
- [x] Exportar o projeto PTI Magic Maker para um repositório GitHub do usuário.
- [ ] Validar end-to-end o cadastro de uma nova conta por e-mail e senha com sessão imediata.
- [x] Adicionar botão acessível para mostrar ou ocultar a senha no login e cadastro.
